# YAKUZA - GG Garage
Standalone test garage with stock GTA V vehicles; no external DLC packs required.

## Installation
Copy `yg_garage` to `resources/[core]/` and add `ensure yg_garage` to server.cfg.

Commands: `/auta` list, `/auto 1` through `/auto 9` spawn, `/usunauto` remove last spawned car.

This is a basic client-side prototype for testing, not a secure server-authoritative vehicle ownership system.
