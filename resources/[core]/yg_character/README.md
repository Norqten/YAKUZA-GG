# YAKUZA - GG Character
Standalone character selection and basic clothing presets/backpacks. Run after spawnmanager and disable yg_spawn to avoid competing auto-spawns.

Commands: /postac to reopen creator. Save uses client KVP (per local FiveM client), not a server-side character database. Not a full GTA5RP editor. Backpack drawable IDs are GTA freemode placeholders and may need tuning. Only one saved appearance per client.
