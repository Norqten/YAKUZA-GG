# YAKUZA - GG

Standalone FiveM PvP server project.

## Status
Initial scaffold. Not yet deployed or tested on a live FXServer.

## Requirements
- FXServer (FiveM server artifacts)
- Cfx.re server license key
- OneSync enabled

## Setup
1. Install FXServer.
2. Copy `server.cfg` and `resources/` into your server data directory.
3. Set your own `sv_licenseKey` in `server.cfg`. Never publish your real key in GitHub.
4. Start FXServer.
